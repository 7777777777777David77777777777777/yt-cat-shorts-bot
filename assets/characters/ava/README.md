# Ava 固定角色參考

此資料夾保存本次確認的原創虛構角色資料：

- [portrait.png](portrait.png)：五官、髮型與妝容參考。
- [full_body.png](full_body.png)：灰色連身運動服、素白短襪的全身比例參考。
- [profile.md](profile.md)：固定的身分、外觀、身形與具名圖片路徑，供所有集數共用。

角色設定為 28 歲成年女性。身高 155 公分、體重 55 公斤、臀圍 86 公分與 D 罩杯為外觀設定，圖片不能作精確尺寸量測。

這兩張圖只定義人物長相與自然身形。每集的服裝、鞋襪、背景及表情由 Markdown 劇本指定；不會要求每集都穿灰色緊身衣與白襪。

在劇本加入：

```markdown
## 角色檔

assets/characters/ava/profile.md
```

角色檔的圖片路徑相對於角色檔所在資料夾，透過「肖像」「全身」指定用途，無須依賴手填的圖片順序。
角色檔只能填身分、外觀、身形與參考圖，不包含本集服裝、場景及表情。
第一幕附上這兩張圖建立本集 `## 服裝` 的全身穿搭；第二至四幕附上同一組主角圖及第一幕圖片。
每幕可用 `### 表情` 指定情緒與目光。鏡頭設定臉不入鏡時，省略表情欄位。

圖片為 AI 生成，非真實模特兒照片。這些檔案與儲存庫一同公開。
